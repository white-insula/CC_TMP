## 必须修正：19-P5把标量调用画成了uint8饱和运算

候选图当前写的是：

```python
cv2.add(250, 10) → 255
```

这行不是产生255的实际调用。本机OpenCV 4.11.0实测，直接传Python整数返回浮点数组：

```text
[[260.], [260.], [260.], [260.]]
```

当前生成脚本真正验证的是二维uint8数组，计算正确。请让图片中的可执行代码与测试保持一致，例如：

```python
a = np.uint8([[250]])
b = np.uint8([[10]])
print(a + b)          # [[4]]
print(cv2.add(a, b))  # [[255]]
```

请修改l19_brightness.py、重新生成19-P5预览，并更新运行记录/哈希。避免把“250 + 10”的数学简写直接放在cv2.add(...)代码里。不要修改正式content.py。
