# manual/ · 手工素材入口(使用说明)

> **人找的图、软件截图、录屏、动画,只放这里,不再手动插进 PPT。**
> 审核「通过」后,重新生成 PPT 时程序会自动把图放到对应页;录屏/动画则把素材需求标成「已就绪」。

## 一、放哪、怎么命名

### PPT生成、手工加工与输出（2026-11-14 用户确认）

正式交付按 `out/online_course/NN_讲名/` 每讲一个文件夹，含PPT、原样复制的单讲脚本Word、素材及清单；逐讲文件夹是唯一正式交付入口，不再另存根目录重复PPT。运行 `python draft/online_course/_package_delivery.py` 直接复制已获准的源课件，只为尚未建包的讲次创建新包，不覆盖既有包、不重建PPT或Word。后续局部更新须同步逐讲包及源课件，更新包清单，再刷新输出台账。

先补齐并登记素材，再生成PPT，再手工制作特殊效果/版式或备注交视频公司，最后存入 `out/online_course/`。下文“不手改PPT”仅适用于素材自动接入阶段，不能阻止用户完成生成后的手工加工。输出状态由助手维护于 `draft/ppt_delivery_status.md` 和 `draft/ppt_delivery_registry.json`；运行 `python draft/online_course/_delivery.py` 刷新。已输出的讲次禁止整讲重新生成；局部修改前备份，源/out不一致时先确认最新版本再同步，避免覆盖手工效果。

### 录屏完成登记例外（2026-11-14 用户规则）

用户告知某讲视频已录制，即在 `录屏完成登记.json` 及必要的素材/录屏清单记为“已录制（用户确认）”，不要求提供路径或文件，不使用脚本检查视频可用性、时长、编码、镜头覆盖或播放结果，不再等待视频审核。后期交由视频制作公司剪辑。下方按文件命名、入库及审核流程不作为此类录屏完成登记的前置条件；未知文件名不在 CSV 中虚构。完成登记仅影响清单，不触发 PPT 页替换、删除、视频嵌入或课件重建。

**文件名 = `节号-p页号-类型-简述.扩展名`**,例:`36-p8-shot-相机隐私设置.png`

- 节号、页号看各节的 `NN/素材需求.md`(那张表的「页」列),一条需求 = 一个页号。
- 同一页放多张图 → 程序自动拼成一张,先后顺序 = 登记表里的行顺序,「角标」列写每张小图左上角的标签。

| 类型 | 含义 | 会不会进 PPT |
|---|---|---|
| `photo` | 找的照片、实物图 | 通过后进 |
| `shot` | 软件运行截图、界面截图 | 通过后进 |
| `diag` | 手工或 AI 画的示意图(**示意图以程序画为主**,这里只放确实要用手工版的) | 通过后进 |
| `rec` | 录屏、实拍视频 | 不进 PPT;通过后素材需求标「已就绪」,剪辑成片时使用 |
| `anim` | 动画 | 同上 |
| `ref` | 仅供参考的草稿(如给程序重画用的样稿) | 永不进 |

## 二、登记表 `素材登记.csv` 各列

| 列 | 怎么填 |
|---|---|
| 文件 | 文件名(与 manual/NN/ 里完全一致) |
| 节 / 页 / 类型 | 与文件名一致 |
| 来源类型 | 自拍/自录、网络检索、AI生成、软件截图、教师自制、待补 |
| 出处 | 网址、AI 工具名、拍摄人等 |
| 授权 | 出版前必须明确(如"自制""已获授权""待核");AI 生成写明并保留 AI 标识 |
| **状态** | **待审 / 通过 / 需改 / 仅参考 —— 只有「通过」的才会进 PPT** |
| 图注 | PPT 和教材里图下的说明文字(同页多张只取第一条) |
| 角标 | 同页拼图时每张小图左上角的标签,可空 |
| 备注 | 审核意见、要改什么 |

## 三、一条素材的完整流程

1. 找到 / 截到 / 录好 → 先丢 `_inbox/`。
2. 对照 `NN/素材需求.md` 确定节号、页号 → 按规则改名,移到 `manual/NN/`。
3. 在 `素材登记.csv` 加一行,状态填「待审」。
4. 审核(内容对不对、和脚本讲的是否一致、来源授权)→ 改成「通过」或「需改」并写备注。
5. 重新生成该节:`python _lib.py NN`(图自动进 PPT,素材需求自动变 ✅)。
6. 跑 `python _sync_check.py`:第 9 项会报命名不对、没登记、页号不存在、通过了但 PPT 没重新生成等问题。

## 四、规矩

- **不再手动往 PPT 里插图**——手插的东西重新生成就丢,且没人知道它从哪来。
- 同一页如果程序也配了图,**程序图优先**,生成时会提示冲突;要换成手工图,请先商量把程序图撤掉。
- 压缩包只作原始存档(`stu_work/archive/`),用的时候解压、改名、登记进这里,不直接从压缩包取用。
