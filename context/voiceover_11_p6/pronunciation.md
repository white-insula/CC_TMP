# 发音与画面适配

本任务为11-P6创建黑图。正式讲解词另见narration_original.txt，不改变正式归档。

| 内容 | 读法建议及含义 |
|---|---|
| create_img.py | create，下划线，I M G，点，P Y；实际画面文件名。原脚本为numpy_image.py，唯一文件名适配须说明。 |
| NumPy / numpy | 清晰读NumPy（常读作“Num pie”），不读成“数字P”。 |
| cv2 | C V 二 |
| np.zeros | N P，点，zeros；意思是全零。 |
| img | I M G；可按字母拼读。 |
| (300, 400, 3) | 高三百、宽四百、三个通道，不能颠倒宽高。 |
| uint8 | U int 八，或结合原意“无符号八位整数”；不可念成“优因特吧”等不明词。 |
| type / ndarray | type；N D array。 |
| shape / dtype | shape；D type。 |
| imshow | im show；函数名是imshow，不是image_show。 |

初稿分段文字中的拼读是待优化候选，允许为自然发音调整空格、停顿和英文拼写方式。实际合成输入须另存，不以这些拼读修改正式脚本。
