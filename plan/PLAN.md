## 五、数字教材要点(Digital Textbook Notes)

### 与纸质教材的本质区别
数字教材 = 「可互动的学习产品」,不只是「一本书」。核心差异:多媒体(视频/动画)、非线性(超链接)、可互动(测验/拖拽)、代码可运行、可随时更新、依托平台。

### 编辑时需特别注意
1. ~~**先定平台和格式**~~ → 按官方口径**格式后置**(由中标出版社定,见二.2);现阶段专注内容与资源。
2. **素材单独管理**——视频/动画/代码/图片文件多,需提前规划文件夹结构与命名规范
3. **代码要「可运行」**而不只是「可看」
4. **交互点提前设计**——哪里放视频、测验、可互动 demo
5. **版本管理**——用 git 记录更新历史

### 对章节地图的影响
骨架不变,但每章需额外考虑三样:📹 配什么视频、🎛️ 哪里做互动、💻 代码怎么放。
另需对齐硬指标:**本书下限 微视频 ≥80 / 虚仿 ≥6 / 动画 ≥369s**,按"内容为纲"分摊到各章(见二.3、三)。
